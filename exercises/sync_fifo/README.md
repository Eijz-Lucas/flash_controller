# 题 6：4×8 同步 FIFO

## 目标与接口

补全 `design.v`，实现深度为 4、数据宽度为 8 bit 的同步 FIFO。`rst_n` 异步低有效；复位后 `count=0`、`empty=1`、`full=0`、`dout=0`。`count` 表示当前有效元素个数，范围为 0～4。`full`、`empty` 由当前个数确定。

在 `clk` 上升沿处理读写请求。有效读从队首弹出一个元素，并把它放入寄存输出 `dout`；没有有效读时 `dout` 保持。空时单独读会被忽略，满时单独写会被忽略。非空且非满时，读写同拍均生效，`count` 不变。满时同拍读写也均生效：读出旧队首，在尾部写入新数据，`count` 保持 4。空时同拍读写只写入，不旁路输出；下一拍才能读出。用环形读写指针实现，指针到 3 后回到 0。

## 功能波形

每列是 `clk` 一个周期，显示上升沿后的值。先写入 `11/22/33/44`（十六进制），满时写 `99` 被忽略；满时同拍读写读出 `11` 并写入 `55`。随后依次读出 `22/33/44/55`；空读不改变输出；空时同拍读写仅写入 `66`，下一拍读出。

## 验证

```sh
make sync_fifo
# 波形：sim/sync_fifo.vcd
```

Testbench 检查复位、顺序、满空、溢出/下溢、满时和空时的同拍读写。通过时打印 `RESULT: PASS sync_fifo`；失败时打印 `FAIL sync_fifo` 并非零退出。
